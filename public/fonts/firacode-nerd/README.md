# FiraCode Nerd Font

Unmodified Regular and SemiBold font files, Fira Code 6.2 with Nerd Fonts patches.
Source: https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/FiraCode
Base font: https://github.com/tonsky/FiraCode

The original metadata and glyphs are preserved. Local installed copies are used
when available; bundled files support visitors without the font installed.
Keep LICENSE and the upstream attribution README with these assets.
