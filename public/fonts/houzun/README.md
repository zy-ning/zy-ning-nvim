# HouZunSongTi

Original, unchanged WOFF2 Unicode subsets from ZeoSeven Fonts (font 63),
HouZunSongTi version 2.001, copyright Houzun 2023, SIL Open Font License 1.1.

Source: https://fonts.zeoseven.com/items/63/
CSS: https://fontsapi.zeoseven.com/63/main/result.css
License text: https://openfontlicense.org/documents/OFL.txt

These subsets cover the profile name and the three existing song titles. Keep
font.css, its original metadata, and OFL.txt with the font files. If those titles
change, add the corresponding original Unicode subsets or allow the Songti
fallback for characters not included here.
